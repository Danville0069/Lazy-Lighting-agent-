5 · Implement in Lazy Lighting
	1	Open Lazy Lighting on the iPhone, connect your HDMI/AirPlay/Lazy Lighting Link projector.
	2	Use Map and make matching shapes (rectangle, custom outline, cube); adjust corners while watching the actual projection. The mapping outline in MapPilot is for rehearsal only.
	3	Choose a shape’s content and import the PNG exported by MapPilot, or select the recommended built-in effect from the generated plan.
	4	Create scenes in Lazy Lighting matching the generated cues; configure BPM, timeline lengths, opacity, transitions and any audio/MIDI controls available in your plan.
	5	Test against the real surfaces and save the project within Lazy Lighting. Recalibrate if the projector moves.
Integration boundary: Lazy Lighting does not publicly document an external project-editing API that I could verify. This tool does not automatically inject scenes, mappings or MIDI assignments into Lazy Lighting. Imported artwork and guided manual setup are supported workflows.
This studio plans conventional video projection mapping. ILDA laser projection is a separate hardware/software pipeline, with additional safety requirements. Never use this app to aim or calibrate high-power laser beams.
